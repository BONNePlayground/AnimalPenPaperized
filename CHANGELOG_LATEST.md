## Animal Pens Paperized 1.4.0

- Adjust the spawn position of released animal
- Fixed item duplication from player inventory in Animal Pens GUI
- Added `animal_cage_pickable` entity type tag that defines which entities can be pickable by animal cage
- Added `water_mob_container_pickable` entity type that defines which entities can be pickable by water mob container
- Added `can_attack_aquarium` item tag that defines items that can attack aquarium to get loot
- Added `can_attack_pen` item tag that defines items that can attack animal pen to get loot
- Added `mace` and `spears` to items that can be used to attack animal_pen and aquarium
- Move `turtle` and `axolotl` from animal pens to aquariums.
- Updated `zombie_horse` food to new tag `zomie_horse_food` (requires config update)
- Updated `squid`, `glow_squid` and `dolphin` food item to `"#minecraft:nautilus_food"` (requires config update)
- Added `nautilus`, `zombie_nautilus` and `camel_husk` to food item config (requires config update)
